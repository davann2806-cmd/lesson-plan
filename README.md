# កិច្ចតែងការបង្រៀនគណិតវិទ្យា (Lesson Plan — សិស្សមជ្ឈមណ្ឌល និង 5E)

**🌐 តំណភ្ជាប់មើលទម្រង់ផ្ទាល់ និងបោះពុម្ព (Live Template):** [https://davann2806-cmd.github.io/lesson-plan/](https://davann2806-cmd.github.io/lesson-plan/)

បណ្ណាល័យទម្រង់ស្តង់ដារ **កិច្ចតែងការបង្រៀនគណិតវិទ្យា** ជាភាសាខ្មែរ ស្របតាមគោលវិធីបង្រៀន **សិស្សមជ្ឈមណ្ឌល** និងវិធីបង្រៀនបែបរិះរក **5E** ដែលរៀបចំសម្រាប់ការបោះពុម្ព (Print / Save as PDF) និងទាញយកជាឯកសារ **Microsoft Word (`.doc`)** លើក្រដាសស្តង់ដារ **A4**។

---

## រចនាសម្ព័ន្ធទម្រង់ស្តង់ដារ (៣ ជួរឈរ × ៥ ជំហាន)

### តារាង ៣ ជួរឈរ
1. **សកម្មភាពគ្រូ**
2. **ខ្លឹមសារមេរៀន**
3. **សកម្មភាពសិស្ស**

### ជំហានទាំង ៥ និងការបញ្ជ្រាបគំរូ 5E
- **ជំហានទី១ ៖ រដ្ឋបាលថ្នាក់រៀន** — ពិនិត្យអនាម័យ សណ្តាប់ធ្នាប់ និងវត្តមានសិស្ស
- **ជំហានទី២ ៖ កិច្ចការផ្ទះ និងរំលឹកមេរៀនចាស់** — កែសម្រួលកិច្ចការផ្ទះ និងរំលឹកចំណេះដឹងមូលដ្ឋានភ្ជាប់មេរៀនថ្មី
- **ជំហានទី៣ ៖ មេរៀនថ្មី** *(បញ្ជ្រាប 5E ដំណាក់កាលទី១ ដល់ទី៣)*៖
  - **១. ដំណាក់កាលបំផុសចំណាប់អារម្មណ៍ (E1)**
  - **២. ដំណាក់កាលរុករក និងស្រាវជ្រាវ (E2)**
  - **៣. ដំណាក់កាលបកស្រាយ និងសំយោគ (E3)**
- **ជំហានទី៤ ៖ ពង្រឹងពុទ្ធិ** *(បញ្ជ្រាប 5E ដំណាក់កាលទី៤ និងទី៥)*៖
  - **៤. ដំណាក់កាលពង្រីកចំណេះដឹង (E4)**
  - **៥. ដំណាក់កាលវាយតម្លៃលទ្ធផលសិក្សា (E5)**
- **ជំហានទី៥ ៖ កិច្ចការផ្ទះ និងបណ្តាំផ្ញើ**
