## រចនាសម្ព័ន្ធទម្រង់ស្តង់ដារ

### ១. ទំព័រទី១ ៖ ក្បាលកិច្ចតែងការបង្រៀន និងការតម្រឹមសញ្ញាភ្នែកមាន់ (`៖`) ស្មើជួរគ្នា
- **អង្គភាពសាលារៀន ៖** មន្ទីរអប់រំ យុវជន និងកីឡាខេត្តកំពង់ធំ / ការិយាល័យអប់រំ យុវជន និងកីឡាស្រុកកំពង់ស្វាយ / **អនុវិទ្យាល័យព្រះក្រសាំង**។
- **ចំណងជើងធំនៅចំកណ្ដាល ៖** សរសេរត្រឹមតែពាក្យថា **«កិច្ចតែងការបង្រៀន»**។
- **ព័ត៌មានទូទៅចូលបន្ទាត់ក្នុងបន្តិច និងតម្រឹមសញ្ញា `៖` ស្មើជួរគ្នាពីលើដល់ក្រោម ៖**
  1. `- មុខវិជ្ជា ៖ គណិតវិទ្យា ថ្នាក់ទី៧` *(បញ្ជាក់ថ្នាក់នៅពីក្រោយមុខវិជ្ជាតែម្ដង)*
  2. `- ខ្លឹមសារមេរៀន ៖ មេរៀនទី១ ចំនួនគត់` *(មិនចាំបាច់ដាក់ជំពូក)*
  3. `- ចំណងជើងរង ៖ ១.៤. វិធីចែកចំនួនគត់`
  4. `- រយៈពេល ៖ ១០០ នាទី`
  5. `- បង្រៀនដោយ ៖ ...` និង `- កាលបរិច្ឆេទ ៖ ...` *(គ្មានជួរដកស្រង់ចេញពីសៀវភៅ)*
  6. `- វត្ថុបំណង ៖` (`+ វិជ្ជាសម្បទា`, `+ បំណិនសម្បទា`, `+ ចរិយាសម្បទា` — រាល់ពេលអក្សរវែងធ្លាក់ចុះបន្ទាត់ទី២ គឺតម្រឹមស្មើនឹងសញ្ញា `៖` ជានិច្ច)
  7. `- គោលវិធី និងយុទ្ធវិធីបង្រៀន ៖` (`- គោលវិធី ៖ សិស្សមជ្ឈមណ្ឌល` និង `- យុទ្ធវិធីបង្រៀន ៖ តាមបែបរិះរក (5E)`)
  8. `- សម្ភារៈឧបទ្ទេស ៖` (`+ សម្រាប់គ្រូ` និង `+ សម្រាប់សិស្ស` — ដាក់នៅខាងក្រោមគេនៃទំព័រទី១)

### ២. តារាង ៣ ជួរឈរ × ៥ ជំហាន (ចំណងជើងជំហានទាំង ៥ នៅចំកណ្ដាល)
1. **សកម្មភាពគ្រូ** (`28%`)
2. **ខ្លឹមសារមេរៀន** (`44%` — ទូលាយសម្រាប់សរសេររូបមន្ត និងប្រមាណវិធីគណិតវិទ្យា)
3. **សកម្មភាពសិស្ស** (`28%`)

ជំហានទាំង ៥ ត្រូវបានដាក់ **នៅចំកណ្ដាលតារាង** និងបញ្ជ្រាបគំរូបង្រៀន **5E**៖
- **ជំហានទី១ ៖ រដ្ឋបាលថ្នាក់រៀន** (៥ នាទី)
- **ជំហានទី២ ៖ កិច្ចការផ្ទះ និងរំលឹកមេរៀនចាស់** (១០ នាទី)
- **ជំហានទី៣ ៖ មេរៀនថ្មី** (៥៥ នាទី — បញ្ជ្រាប 5E ដំណាក់កាលទី១ ដល់ទី៣)៖
  - **១. ដំណាក់កាលបំផុសចំណាប់អារម្មណ៍ (E1)**
  - **២. ដំណាក់កាលរុករក និងស្រាវជ្រាវ (E2)**
  - **៣. ដំណាក់កាលបកស្រាយ និងសំយោគ (E3)**
- **ជំហានទី៤ ៖ ពង្រឹងពុទ្ធិ** (២២ នាទី — បញ្ជ្រាប 5E ដំណាក់កាលទី៤ និងទី៥)៖
  - **៤. ដំណាក់កាលពង្រីកចំណេះដឹង (E4)**
  - **៥. ដំណាក់កាលវាយតម្លៃលទ្ធផលសិក្សា (E5)**
- **ជំហានទី៥ ៖ កិច្ចការផ្ទះ និងបណ្តាំផ្ញើ** (៨ នាទី)

- **បំបែកសន្លឹកក្រដាស A4 ផ្ដេកដាច់ៗពីគ្នាដូចពេលបោះពុម្ព (`1:1 WYSIWYG Sheets`) ៖** នៅលើអេក្រង់ ឯកសារត្រូវបានផ្ដាច់ចេញជាសន្លឹកក្រដាស `297mm × 210mm` ដាច់ៗពីគ្នា (មានចន្លោះខណ្ឌចែក លេខទំព័រ `ទំព័រទី ១ / ...` និងក្បាលតារាងទាំង ៣ ជួរឈរឡើងវិញលើរាល់ទំព័រថ្មី) ដែលដូចគ្នាបេះបិទ ១០០% ទៅនឹងទំព័រដែលព្រីនចេញលើក្រដាស ឬ PDF។
